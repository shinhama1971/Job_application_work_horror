# 授業資料Part.9と森の草の対応

確認資料：ユーザー提供の「01-授業資料.zip」内の「09. ComputeShader実践 - 草レンダリング.pdf」、全39ページ。2026年11月6日に本文と実装例の図を確認しました。ページはPDFの先頭を1とした番号です。

| 資料の説明 | 今回の場所・対応 |
|---|---|
| p.12・17〜19：距離によって形や情報量を減らす | ForestGrass.cpp::Draw。5節→3節→三角形1枚、本数も減らす。中景の交差板方式は使っていません |
| p.13・26〜27：群生、丈の差、根元の幅、不均一な配置 | PlantBladesのジッターと2段階のノイズ、草丈・色の差。grassVSの根元を細める幅の式 |
| p.21〜22：至近距離の草を縮める | grassVSで水平距離2〜14の範囲を縮め、近くで視界を塞ぎにくくする |
| p.23：下を向いたとき、カメラの上方向へ草を曲げて側面を見せる | grassVSで、見下ろすほど（視線の下向きが0.25〜0.85）葉先をカメラの上の向き（水平にした向き）へ倒し、葉の幅をその横の向きへ寄せる。技術デモ（F2）の「草をカメラの上方向へ曲げる」でなし・ありを比べられる（2026年11月7日） |
| p.29：CSで状態を管理し、VSが曲線から頂点を作る | 不変のBlade（48バイト）と動くBladeState（32バイト）へ分離。CSのUAV→VSのSRVとして使う |

資料の例では風にPerlinノイズのテクスチャを使いますが、本作では既存のFastValueNoiseを計算して流し、sinのそよぎを重ねます。プレイヤーの力は目標位置へ加えてばねで戻し、2分割の半陰的オイラー法、長さの補正、地面より上の高さ制限を加えています。制御点の中間2点は保存せず、葉先からVSで復元します。

本作向けの追加は、小道・木・岩・研究所・枯れた茂みの足元と、見えている水たまりの水面（Ground::IsNearVisiblePuddle）を避ける配置、40単位の区画のCPU視錐台カリング、配置の再読み込み、ホラー向けの照明・霧・色調です。資料p.23のカメラ上方向へ曲げる方式は11月7日に追加しました。遠くの幅をカメラの横方向へ寄せる処理は、それとは別の近似です。資料p.33のAsync Compute、p.36のHi-Zオクルージョンカリング、p.37のテクスチャ補間によるベジェ評価も未実装です。
