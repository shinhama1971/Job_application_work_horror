## 11月9日の続きで足したもの（作者の指示）

- **モデルの読み込みを速くした**：`StaticMesh` が Assimp で変換した結果を `Job_application_work_horror/cache/model/*.mesh` に保存し、次からはそれを読む。
  Debug 版の森で、モデルの読み込みの合計が約920ミリ秒から約34ミリ秒になった。元の FBX・OBJ を書き換えると（大きさか更新日時が変わると）自動で読み直す。
  `cache/` は `.gitignore` で外している。おかしいと思ったら `cache` フォルダを別の場所へ移せば、次の起動で作り直す。
- **岩に PBR の材質**：`shader/rockSurface.hlsli`・`rockPS.hlsl`。色むら・ギザギザのひび・苔・地衣類・鉱物の粒（照らすと点々と光る）・地面際の湿り。
  見た目の強さを変えるときは `rockSurface.hlsli` の数値（ひびの `smoothstep` の幅、苔の `mossPatch`、粒の `RockGrainSpark` の 0.78 など）。
- **木・倒木・茂みに樹皮の PBR の材質**：`shader/barkSurface.hlsli`・`barkPS.hlsl`。木目に沿った縦の溝・板の横のひび・剥がれて出た灰色の地の木・苔・地衣類・根元の湿り。
  木目の向きは `Wall` がマテリアルの環境の色で渡している（木と茂みは上、倒木は長い向き）。溝の間隔は `GetBarkPlates` の `spacing`、剥がれの量は `peel` の 0.76。
- 自動撮影で道順を足して確かめるときの注意：撮影の瞬間はキーフレームの時刻より少し後なので、撮る位置の後に同じ位置の「止まる」キーフレームを置く。目の高さは地面から約40。

## 1面の録音と嘘の無線

- 中央ホール・南西の広間・西棟・書類保管室に録音機を1台ずつ配置。調べると琥珀色の字幕で3行流れ、ランプが赤の点滅から緑の点灯に変わる。再生数はリザルトの「今回の発見」と完全探索の判定に反映する。
- 1本目のヒューズを取ると、無線が書類保管室へ誘う。入室と影の出現を字幕の再生中も拾い、台詞は順に流す。4つ目の録音の後は「……聞いたのか。」に続けて「通信途絶」を表示し、嘘の無線が止まる。
- 修正前の撮影では、西棟への切り替え中に位置を補間したため、書類保管室を1フレーム通過し、入室の台詞が西棟で先に出ていた。切り替え前後のキーフレームを同時刻にして、途中の座標を通らないようにした。
- 修正後の確認用撮影では、書類保管室で入室時の台詞（05d）と「ライトを消せ」（05e・05f）が順に出た。録音1と4を自動再生し、それぞれ琥珀色の字幕で3行流れること、録音4の後に応答と通信途絶が出ること、中央ホールの録音機のランプが緑になることを画像で確かめた。確認用の撮影位置、自動再生、ヒューズ数の上書きは取り除いた。

- 一時処理を外した最終版を Release・Debug（x64）でビルドし、どちらも警告0・エラー0。Release の `--capture`（1面→2面）と `--forest --capture` はどちらも最後まで通り、終了コード0。画像と動画はリポジトリ外の一時フォルダに出した。

## 次の候補（シェーダーとゲーム性を先に）

1. 画面（レンズ）に付く雨粒：後ろの景色をゆがめて映し、流れ落ちる（雨を戻すときに）。
2. 稲光：ときどき空が光って森全体と木の影が一瞬見え、遅れて雷の音。光った瞬間だけ遠くに人影。
3. 濡れた木や岩：上を向いた面ほど暗く光り、雨の筋が流れる。
4. 「難しい」という意見への対応：迷っている時間に合わせてヒント（H）を変える、ヒューズの近くで音の手がかり。
5. （済み）モデルの読み込みを、一度変換した形式で保存して速くする。
6. （済み）木・倒木・茂みにも、岩と同じ作りで樹皮の材質（縦の筋・剥がれ・苔）を付ける。
7. 斜めの枝にも筋を沿わせる（Maya のスクリプトで枝ごとの向きを頂点の値に入れて渡す）。
