  タイトルの3つ目「1面　森を飛ばして始める」は、受信記録から全部見せる導入（`IntroScene`）から1面へ。
- **無線の文章**：`Job_application_work_horror/StoryText.h` に書いた行の数だけ流れる（森の字幕 `ForestRadio`、導入 `IntroScene` とも、行の数と長さから自動で時刻と場所を決める）。
- **雨**：今は止めている。`ForestScene.h` の `RainEnabled` を `true` にすると、雨粒・しぶき・水たまりの輪・雨音がまた出る。
- **効果音**：作者が用意した MP3 を WAV にして差し替えた（足音は研究所の中と森で別、扉のきしみ、鍵のかかった扉、水滴、西棟の排水）。一覧は README の「効果音の差し替え」。

## 次の候補（シェーダーとゲーム性を先に）

1. 画面（レンズ）に付く雨粒：後ろの景色をゆがめて映し、流れ落ちる（雨を戻すときに）。
2. 稲光：ときどき空が光って森全体と木の影が一瞬見え、遅れて雷の音。光った瞬間だけ遠くに人影。
3. 濡れた木や岩：上を向いた面ほど暗く光り、雨の筋が流れる。
4. 「難しい」という意見への対応：迷っている時間に合わせてヒント（H）を変える、ヒューズの近くで音の手がかり。
5. モデルの読み込みを、一度変換した形式で保存して速くする（Debug 版の起動がさらに速くなる。大きな変更なので審査会の後）。
