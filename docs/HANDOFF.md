- **水たまりの反射をはっきりさせた**：SSRの歩数を増やし、当たりを二分探索で詰め、映り込みを強め、よく映る所の床の霧を弱めた。反射の光線は、穏やかな水面の向きに波を3割だけ足した向きで飛ばし（`wetFloorPS.hlsl` の `reflectionNormal`）、画面の外の壁・天井にコンクリートと天井板の模様を付けた（`rayReflection.hlsli` の `GetRoomReflectionDetail`）。作者の希望で、カメラを増やす平面反射には戻さず、レイを飛ばす方式のまま直している。続けて、画面の外の物を PBR の環境マップ（t14）から部屋の形に当たった位置で読むようにし（`ReflectionParams.w` が1のとき）、前のフレームの画面の縮小画像で、映る物が離れているほどぼかすようにした（`ScreenSpaceReflection::Prepare`）。重さは測るたびの揺れの中で変わらなかった。自動撮影の縮小した画像では違いが小さかったので、実際に歩いて、真上の照明や後ろの壁が水たまりに映るか、遠くの映り込みのぼけ具合が自然かを確かめる。作者の録画で分かった「かくかく」（床を見下ろしたとき、SSR が床そのものに誤って当たり、明るい床がギザギザの塊で映って跳ねる）は、当たった所の高さで床への当たりを捨てて直した（`TraceScreenSpaceReflection` の `minHitHeight`）。録画と同じ場面（1面の配電盤のそばの床を照らしながら歩く）で、まだ跳ねないかを確かめる。ぼけが強すぎるときは `wetFloorPS.hlsl` の `1.0f / 60.0f`（距離60で1段）を小さくする。撮影で、1面の机の脚が水面にくっきり映るようになったのを確かめた。西棟だけ本描画が約0.4ms増えた。平面反射ほど全部は映らない（画面の外の物は、部屋の形と小物の箱で埋めるため）。実際に歩いて、まだ濁って見える所があれば、どこか（1面・2面・森、ライトの中か外か）を伝えてもらう。
- **雨で濡れた岩と樹皮**：`shader/forestWetness.hlsli`。雨の強さに合わせて、上を向いた面ほど暗く濡れて光沢が出て、横の面には水の筋が流れ落ちる。撮影で岩（上の面が暗くつやっと光る）と枯れ木（幹が暗く、縦の水の筋が光る）を確かめた。強さを変えるときは `forestWetness.hlsli` の数値（暗くなる量の `0.58f`、筋の数の `step(0.62f, ...)`、流れる速さの `flowSpeed`）か、`ForestRain::Update` の `0.5f + 0.5f * m_Intensity`。
- **1面の水たまりの水滴の音**：雨漏り以外の水滴（近い水たまりに落ちる最大24粒）は音を鳴らしていなかったので、70以内に落ちたものを、0.25〜0.5秒の間を空けて鳴らすようにした（`WaterEffectSystem::UpdateFallingDrops`、`m_DropSoundCooldown`）。位置付きの音の枠は16なので、多すぎると足音などが途切れる。実際に1面を歩いて、聞こえ方と、ほかの音が途切れないかを確かめる。
- **レンズのしぶき**：水たまりを踏んだときの画面の水滴を作り直した。走ったときだけ、画面の下の毎回違う位置に小さな粒が付き、景色を逆さに映しながら流れ落ちて約2.6秒で乾く。歩くだけでは付かない。撮影では一時的な処理で付け続けて見た目を確かめた（処理は消した）。実際に水たまりを走って、付く頻度と目立ち方を確かめる。
  その後の森の計測では、ブルームや画面効果など変更と関係ない段階まで約2倍になっていたため、GPU の熱で遅くなっていたと考えている（水たまりの波の段階も同じ割合）。熱が冷めた状態でもう一度測る。
  なお、1面の計測を1回目に動かしたとき、4地点目の前で結果を書かずに終わった（終了コード0）。もう一度動かすと最後まで通ったので、原因はまだ分かっていない。
- **効果音**：作者が用意した MP3 を WAV にして差し替えた（足音は研究所の中と森で別、扉のきしみ、鍵のかかった扉、水滴、西棟の排水）。一覧は README の「効果音の差し替え」。
- **Debug 版の起動**：草を植える処理を速くした。モデルの読み込み（Assimp）も、2回目の起動からは変換済みの形式を読むので、森では約0.03秒になった（下）。残りは主に D3D のデバイス作成（ドライバー、約1.5〜2秒）。

## 水たまりの反射の調整（11月11日）

- SSRは今の深度で見つけた当たりを前フレームのカメラへ投影し直し、前の深度と合う所だけ色を使う。コマ落ち演出で色を取り込まなかったフレームや場面切り替えの直後は、部屋の形から反射を求める。
- 部屋の形から求めた反射を主にし、SSRと少しずつ撮り直す環境マップは細部の補助にした。見下ろす角度の映り込みと照り返しを弱め、反射を揺らす傾きには足音や水滴で実際に広がる波を使う。
- Release・Debug（x64）は警告0・エラー0。Debugの自動撮影は1面から2面と森が終了コード0で完了した。
- 同じ道順の撮影画像を比較し、西棟の排水バルブ付近で照り返しが弱まり、床の継ぎ目と足音の波紋が見えることを確認した。水面に人影が出る演出も確認した。
- 作者の画像を受け、配電盤の隣などで画面外の扉も映るよう、扉板を開閉角度に追従する箱としてレイ反射へ渡した。近くの壁と扉の足元では、斜めからの映り込みを強めた。遠い壁や天井に近い部分は徐々に弱め、西棟の広い水面で濃い帯ができないようにした。水面で跳ね返った懐中電灯の光を反射先の照明に加え、床の白飛びを抑えた。
- 配電盤の隣を2つの位置から撮影し、反射を切った画像と比べて、水面に扉と壁の境目が出ることを確認した。確認用の撮影位置と早期終了は取り除いた。最終調整後も Release・Debug（x64）の警告・エラーは0で、Release の1面から2面と森の自動撮影は終了コード0だった。
- 実際に遊ぶときは、1面の配電盤付近や西棟で水たまりを照らし、横に歩いたり視点を振ったりして反射の輪郭の動きを確かめる。

- 水面メッシュが距離で切り替わると反射が急に変わるため、SSRと部屋の形から求める反射を、画素までの距離でそれぞれ徐々に弱めた。SSRは水面に近すぎる当たりの先にある壁や小物も探す。西棟で少し離れて戻る道順を、通常と遠距離扱いに固定した場合で撮影し、対応する3枚の画像が一致した。一時確認の処理は取り除いた。

## 次の候補（シェーダーとゲーム性を先に）

1. 画面（レンズ）に付く雨粒：後ろの景色をゆがめて映し、流れ落ちる（雨を戻すときに）。
2. 稲光：ときどき空が光って森全体と木の影が一瞬見え、遅れて雷の音。光った瞬間だけ遠くに人影。
3. （済み）濡れた木や岩：上を向いた面ほど暗く光り、雨の筋が流れる。
4. 「難しい」という意見への対応：迷っている時間に合わせてヒント（H）を変える、ヒューズの近くで音の手がかり。
5. （済み）モデルの読み込みを、一度変換した形式で保存して速くする。
6. （済み）木・倒木・茂みにも、岩と同じ作りで樹皮の材質（縦の筋・剥がれ・苔）を付ける。
7. 斜めの枝にも筋を沿わせる（Maya のスクリプトで枝ごとの向きを頂点の値に入れて渡す）。
