# 画質1〜3の参考計測（2026-10-31）

RTX 3050 6GB Laptop、1920×1080、垂直同期なし。1面7地点・2面2地点を同じ自動ルートで、各条件180フレーム測りました。GPUタイムスタンプの結果です。内蔵GPUのPCは未計測です。演出・霧・照明には時間変化があり、背景でコンパイルが動作した時間もあるため、単一GPUでの参考値として扱います。全地点で設定番号順に必ず速くなるという保証はありません。

| GPU合計、ライトON（ms） | 設定1 | 設定2 | 設定3 |
|---|---:|---:|---:|
| 開始地点（壁の文字の前） | 2.53 | 3.89 | 3.97 |
| 開始地点から廊下の奥 | 2.81 | 4.06 | 4.56 |
| 中央ホール | 2.81 | 4.42 | 4.52 |
| 左の倉庫 | 3.12 | 4.41 | 4.51 |
| 暗証番号の扉 | 2.83 | 4.23 | 4.13 |
| ループ廊下 | 2.84 | 4.19 | 4.10 |
| 西棟（浸水した広間） | 3.31 | 4.62 | 4.52 |
| 2面（裸電球の下） | 2.65 | 3.62 | 3.66 |
| 2面（廊下の奥） | 2.67 | 3.71 | 3.95 |

設定1はSSAO・電球の影・光の筋・PBR環境マップを停止します。設定2はSSAOと光の筋を半解像度、環境マップを4フレームごとに1面更新し、電球の影を停止します。設定3は電球の影と環境マップの更新を毎フレーム行います。初回は環境マップの6面をそろえます。画質設定を変えても描画用バッファの確保そのものは維持します。

計測上、設定1のSSAO・電球の影・環境マップは0、設定2の電球の影は0、設定3の2面では電球の影が稼働しました。中設定の更新休止時に環境マップを破棄しないよう修正してから再計測しています。

「本描画」の区間にはSSAOと光の筋の準備も含みます。内訳を単純に足すと二重計上になります。また環境マップ単独の平均は更新したフレームだけの値であり、設定2の1フレーム平均の負荷とは違います。

コマンド例：`Job_application_work_horror.exe --benchmark <保存先> --effect-level 1`（1〜3）。計測時だけ設定を上書きし、ユーザーの設定ファイルへは保存しません。RAW計測ログは本チャットの作業報告一式へ添付しています。

ビルド確認は検証コピーでコンパイラー・リンカーのPDB出力を無効にして実施しました。元のプロジェクトのPDB設定は維持しており、この環境のMSPDB140.DLL不一致は未修復です。
