# 森の草：草あり・なしの参考計測（2026年11月6日）

RTX 3050 6GB Laptop、1920×1080、エフェクト3、垂直同期なし、確認用Release。3地点でライトOFF/ONを各180フレーム測りました。下表はライトON、草あり→草なし→草ありの順。草ありは2回の平均で、時刻によって風・霧・水面が変化するため草だけの厳密な単独時間ではありません。

| 地点 | 草なし GPU合計 | 草あり GPU合計 | 差 | 描画本数 / 区画 |
|---|---:|---:|---:|---:|
| 森（開始地点の小道） | 2.58ms | 3.58ms | +1.00ms | 32,659 / 86 |
| 森（街灯の横の草むら） | 2.88ms | 3.52ms | +0.64ms | 24,106 / 87 |
| 森（研究所の手前） | 2.74ms | 3.37ms | +0.62ms | 20,248 / 63 |

植えた本数は264,868本です。草の計算は「水たまりの波」と合算、草の描画は「本描画」と合算されます。RAWログはチャットの確認資料に添付しました。内蔵GPUでの計測はしていません。

比較は `--benchmark <保存先> --forest --effect-level 3`。草を止めるときだけ、起動前に `SIGNAL_LOST_DISABLE_FOREST_GRASS=1` を設定します。
