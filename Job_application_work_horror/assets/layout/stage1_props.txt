# ============================================================================
# 1面の小物の配置（PropLayoutFile が読む）。Debug版では、ゲームを動かしたまま F5 で読み直せる。
# 扉・アイテム・バルブなど、進行のコードが使う物は Stage1Layout.cpp に残している。
#
#   color 名前 r g b [metal 粗さ [金属らしさ]] [rough 粗さ]

#   prop 名前 x y z 幅 高さ 奥行き 色 光る色 光沢 当たり判定(0/1) [noshadow] [weathering] [room] [glow 範囲 強さ] [model モデルの名前]
#   place 名前 x y z [yaw 度] [size 幅 高さ 奥行き]   （進行のコードが作る物の置き場所。ファイルの最後にまとめている）
#   spot 組の名前 x y z   （候補の場所。同じ組を何行も書き、プレイごとに1つを選ぶ。ヒューズと鍵の落ちている場所）
#
#   room を付けた壁は、部屋の角の暗がり（roomOcclusion.hlsli）と水面・鏡のレイ反射が「部屋の形」として使う（32枚まで）。
#   建物の壁・柱も、ここに書いている（weathering でパネルの継ぎ目・ひび・水の跡・カビを描く）。
#
#   model を付けると、見た目だけを Maya で作ったモデル（tools/maya/build_wall_props.py）にする。当たり判定・影・水面に映す箱は箱のまま。
#   モデルは箱の大きさに合わせて伸び、長い物（shelf_long・shelf_short・beam・pipe_pole）は箱の一番長い向きへ回る。
#   名前の一覧は Wall.cpp（shelf_long shelf_short desk_top desk_leg crate debris beam pipe_pole cabinet service_box pump tank drain column warning_lamp safe_bulb desk_lamp_shade desk_lamp_arm desk_lamp_base pipe_run door_indicator hanging_cord）
#
#   PBRの仕上げ：metal は金属（色が映り込みの色。磨いた鉄で0.55前後、錆びて黒ずむほど低い）、rough は金属でない物。
#   metal の後ろの金属らしさ（省くと1）は、汚れや酸化の膜で覆われた分だけ下げている（暗い場所でも形が分かるよう、拡散反射を少し残す）。
#   粗さは 0.045（鏡）〜1（ざらざら）。付けない色は、光沢の強さから粗さを換算する。
#
# 座標の単位は全ステージ共通（床の高さは y=-100、天井の下面は y=-48.5）。
# ============================================================================
